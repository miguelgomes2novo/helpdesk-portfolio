# Guia para atualizar o projeto no GitHub

1. Instale Git, Python e VS Code.
2. Abra o terminal do VS Code na pasta do projeto.
3. Clone seu repositório com:
   `git clone https://github.com/miguelgomes2novo/helpdesk-portfolio.git`
4. Entre na pasta: `cd helpdesk-portfolio`
5. Execute o projeto conforme o README.
6. Depois de fazer alterações, use:
   `git add .`
   `git commit -m "Descreve a melhoria realizada"`
   `git push origin main`

Os arquivos ignorados pelo .gitignore (como banco de dados e .venv) não devem ser publicados.
